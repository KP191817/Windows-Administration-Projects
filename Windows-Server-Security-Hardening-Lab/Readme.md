# Windows Server Security Hardening Lab

## Project Overview

This project demonstrates the implementation of security hardening controls within a Windows Server 2022 enterprise environment.

The lab focuses on applying security best practices using Group Policy, Windows Defender, Windows Firewall, Advanced Audit Policies, Security Event Monitoring, and Security Verification procedures.

The objective of this project was to develop practical skills in securing Windows Server infrastructure while following enterprise administration and security management practices.

---

# Key Achievements

* Implemented enterprise password policies
* Configured account lockout protection
* Deployed centralized security settings using Group Policy
* Configured security auditing and event logging
* Verified Windows Defender protection status
* Implemented Windows Firewall hardening
* Reviewed User Rights Assignments
* Configured Advanced Audit Policies
* Performed Security Event Monitoring
* Conducted security verification and reporting
